استيراد البيانات

ارفع ملفات .sql أو قواميس .xlsx (ملفًا أو أكثر) وسيحللها التطبيق تلقائيًا إلى جداول وعلاقات وأنظمة فرعية، أو استعد نسخة محفوظة سابقًا.

استيراد مخطّط من ملف SQL ▾
ارفع ملف .sql (MySQL / Oracle / PostgreSQL / SQLite) وسيتم تحليل الجداول وعلاقات المفاتيح وتصنيف الأنظمة تلقائيًا.
استيراد قاموس البيانات (Data Dictionary .xlsx) ▾
ارفع قاموس بيانات .xlsx (ملفًا أو أكثر؛ كل ورقة = جدول: إسم الحقل / النوع / الطول / PK / FK / المرجع) وسيحوّله التطبيق لأكواد حسب نوع قاعدة البيانات المختار ويرسم المخطط لجميع الجداول معًا. يمكنك أيضًا توليد أو حذف أعمدة التدقيق تلقائيًا.
استعادة نسخة محفوظة ▾
استعد نسخة SQLite كاملة أو لقطة ترتيب JSON سبق تصديرها.

تصدير البيانات

صدّر المخطط الحالي كصورة أو كود أو قاموس بيانات، أو نزّل نسخة احتياطية من التطبيق.

تصدير المخطط كصورة (SVG / PNG) ▾
تنزيل الرسم الحالي كملف SVG متجهي أو PNG بجودة عالية بأبعاد المخطط الكاملة.
تقرير HTML تفاعلي مستقل (Single-File Offline Report) ▾
تصدير المخطط بالكامل مع قاموس البيانات التفاعلي ومحرك البحث الداخلي في ملف HTML مستقل يعمل 100% بدون إنترنت ولا خادم، لمشاركته مع العميل أو فريق العمل أو إرفاقه في وثائق المشاريع.
تقرير PDF معماري أنيق (Executive Data Dictionary PDF) ▾
توليد وثيقة PDF منسقة ومجدولة تحتوي على مؤشرات المعمارية، ملخص المخطط، وجداول الحقول والأنواع والقيود المرجعية لتوثيق المشروع رسميًا.
تصدير سكربت DDL ▾
توليد سكربت إنشاء كامل للمخطط الحالي بلهجة SQL أخرى (MySQL / Oracle / PostgreSQL / SQLite / SQL Server).
قاموس البيانات (Data Dictionary .xlsx) ▾
توليد قاموس بيانات Excel (.xlsx) منسق ومفصل يحتوي على كافة الجداول، الحقول، الأنواع، المفاتيح الأساسية والعلاقات للمخطط الحالي مباشرة، أو من ملفات كود خارجية.
أو توليد القاموس من ملفات SQL خارجية مرفوعة:
نسخة احتياطية من التطبيق ▾
نزّل نسخة كاملة من قاعدة بيانات SQLite تشمل كل المواضع والإعدادات والأنماط المحفوظة.
تصدير لقطة JSON للترتيب الحالي (مواضع الجداول، الحقول المخفية، العرض).
